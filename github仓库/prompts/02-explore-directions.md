# Prompt 02 — 探索三个真正不同的设计方向

基于 `brief.md`，先不要写代码。提出 3 个有实质差异的视觉/交互方向。

每个方向必须包含：名称与设计主张、信息结构和首屏构图、字体/排版节奏、颜色/材质/边界/图像策略、主要交互隐喻、适合用户任务的理由、风险与可访问性考虑、应避免的常见套路及原因。

三种方案必须在结构、信息组织、视觉隐喻或交互模型中至少两个方面不同；只换配色不算不同方向。

如果使用随机 seed，请记录 seed，并解释它如何影响设计选择。不要将 seed 本身展示在产品中。

输出 `directions.md`。最后给出一个推荐，但明确保留人类选择权。不要修改代码。
