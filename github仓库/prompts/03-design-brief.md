# Prompt 03 — 将选择转成可执行设计 Brief

人类已选择方向：在此填写方向名称与反馈。

请将 `brief.md` 和 `directions.md` 整理为 `design-brief.md`，包含：设计主张与目标用户；页面信息架构和内容顺序；字体层级、字号范围、行高和宽度原则；色彩角色和对比度要求；间距、边框、阴影、圆角的使用规则；图像/视频用途、构图、比例、裁切与加载策略；关键组件和交互状态；桌面/移动端行为；必须保留的项目约束；反模式及原因；可验证的验收标准。

不要机械禁止某种风格元素。每个显著视觉选择都应有与产品任务相关的理由。缺少事实时标注假设，不得编造产品数据。
