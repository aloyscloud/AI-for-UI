# Prompt 04 — 主力编码代理执行

请先阅读 `brief.md`、`design-brief.md` 和现有代码。先报告项目结构、技术栈、将修改的文件及风险；然后再实现。

约束：保留不相关功能、路由、内容事实和埋点；尽量复用现有组件与设计系统，不要无理由重写；不得伪造指标、客户评价或产品能力；仅在 design brief 说明价值时引入图像、视频、复杂动效或 3D；生成资产必须记录在 `asset-manifest.md`；实现适用的默认、焦点、加载、空、错误和成功状态；运行项目可用的构建、lint 和测试；不得声称未执行的测试通过。

完成后输出：修改文件与原因、如何运行、已执行检查及结果、尚未验证内容、下一步截图命令或操作。
