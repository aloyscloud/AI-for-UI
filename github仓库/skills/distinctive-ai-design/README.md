# distinctive-ai-design — Reference & Adaptation Workspace

此目录用于学习并逐步实现 AI UI 设计工作流。在核实来源文件的许可证前，不要直接复制第三方 Skill 的完整文件。

## 引入前检查

1. 确认来源仓库的准确 URL、作者与 LICENSE。
2. 若没有明确许可证，不要直接复制完整文件到公开仓库；可保留来源链接、总结理念并独立实现。
3. 若许可证允许复制，保留所要求的版权声明、LICENSE 和 NOTICE。
4. 在 `CHANGELOG.md` 记录每个本地改动。
5. 完成静态检查和真实端到端实验后，再标记为可用。

## 目标工作流

Explore → Human Select → Define → Build → Capture → Independent Review → Refine → QA.

当前目录为占位说明。只把归属清晰、许可明确并经过验证的 Skill 文件放在这里。
